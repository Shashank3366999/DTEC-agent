# First message

Paste the English one as the agent's **First message**. If the ElevenLabs language settings let you set a first message per language, add the Arabic one for Arabic.

## English

Hello, I'm the DSO Visitor Guide, an AI assistant. Where would you like to go today? You can speak English or Arabic.

## Arabic

مرحباً، أنا دليل الزوار في واحة دبي للسيليكون، مساعد يعمل بالذكاء الاصطناعي. إلى أين تريد أن تذهب اليوم؟ يمكنك التحدث بالعربية أو الإنجليزية.

> Ask an Arabic speaker to check the Arabic before the demo.
